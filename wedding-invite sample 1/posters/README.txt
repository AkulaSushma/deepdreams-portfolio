DEMO POSTERS
============

Save the ceremony poster images into THIS folder with EXACTLY these names,
and the live demo (invite.html?demo) will show them automatically:

  welcome.jpg          - the couple welcome poster (shown after the doors open)
  nichayathartham.jpg  - engagement / trace-the-heart reveal
  haldi.jpg            - haldi / rub-the-turmeric reveal
  muhurtham.jpg        - wedding / light-the-diya reveal
  reception.jpg        - reception or sangeet / tap-the-dhol reveal

JPG or converted PNG both work (keep the .jpg name). Portrait 2:3 looks best.
If a file is missing, the demo gracefully shows the classic written card instead.

Couples building their own invitation upload their own posters from the editor
(Celebrations -> Ceremony poster -> Upload image / Get AI prompt).
