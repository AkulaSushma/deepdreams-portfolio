Each script is an independent k6 test entry point (`view-one.js`, `view-many.js`, `publish.js`, `upload.js`, `one-token.js`) sharing a small common module `_shared.js` that validates `BASE_URL`, blocks accidental production runs via hostname regex matching, parses `SLUGS`/`CODES` env vars, and provides realistic fixture data via `content(n)` and `jsonHeaders`. Scripts declare their own `options` with per-scenario executors (`ramping-vus` for viewing spikes, `per-vu-iterations` for simultaneous publish/upload bursts) and thresholds enforcing pass/fail (e.g. p95 latency, zero errors, CDN hit rate). Custom metrics (`Counter`, `Rate`) are exported per script and summarized via `handleSummary` hooks producing human-readable PASS/FAIL output. The tests target three server endpoints under `BASE_URL`: `/invite/:slug` (GET), `/api/publish` (POST), and `/api/publish/preflight` (POST returning signed storage URLs used by PUT). Dependency direction is one-way: all scripts import only from `_shared.js`; there is no cross-import between test files.
