Each file is a thin Netlify Functions handler that delegates to a corresponding handler in `../../api/admin/` (`login.js`, `site.js`, `tokens.js`) through a shared `bridge` adapter from `../lib/bridge`. The three files map directly to three admin routes: `/api/admin/login` (authentication), `/api/admin/site` (list/take offline/rollback sites), and `/api/admin/tokens` (list/mint/revoke activation codes). This layering keeps the serverless surface minimal — all business logic lives under `api/admin/`, while this module only wires routing and request/response translation via the bridge.
