Each file is a thin Netlify Functions adapter: it requires the shared `../lib/bridge` wrapper and re-exports its handler as `exports.handler`, delegating to the corresponding handler in `../../api/publish/{index,preflight,recover}.js`. The three files map directly to three HTTP routes — `/api/publish` (publish), `/api/publish/preflight` (preflight), and `/api/publish/recover` (recover) — so this module contains no business logic; all request/response handling lives in the sibling `api/publish` package. Dependency direction is strictly inward: functions → bridge → api handlers.
