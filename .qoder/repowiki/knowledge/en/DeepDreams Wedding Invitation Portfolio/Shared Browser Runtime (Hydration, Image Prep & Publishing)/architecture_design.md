Four self-contained UMD-style scripts loaded via `<script>` tags that expose a single global (`DD_HYDRATE`, `DD_IMAGE_PREP`, `DD_LIMITS`, `DD_PUBLISH`) while also supporting CommonJS `require` for server reuse. Dependency direction is one-way: `image-prep.js` and `publish-client.js` read shared constants from `limits.js` (via `window.DD_LIMITS` or an inline fallback), and `hydrate.js` is independent — it only reads `window.DD_SITE`/`DD_PUBLISHED` injected by the server. There are no cross-file imports between the four modules; they communicate through well-defined data shapes: markers (`@m0`, `@m1`, …) in `content` paired with a `media[]` array of image descriptors, and preflight/upload descriptors carrying `{sha256, bytes, type, w, h, variant}`. The module boundary is the browser/server split: everything here runs on the client and never trusts untrusted input beyond what the server already validated, with server-side re-checks documented as the authoritative enforcement layer.
