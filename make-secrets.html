What to do with them

  1. Open a new browser tab and go to dash.cloudflare.com and log in.
  2. On the left menu, click Workers & Pages.
  3. Click on your project: deepdreams-portfolio.
  4. Click Settings → Variables and Secrets (or "Environment variables").
  5. Add these 5 entries one by one. For each: click "Add", type the Name exactly as shown, paste the Value, Save.
Name (type exactly)Value (where it comes from)
TOKEN_PEPPER Copy from Code 1 above ↑
ADMIN_SESSION_SECRET Copy from Code 2 above ↑
ADMIN_PASSWORD Make this up yourself — any password you like (8+ letters). This is what you will type to log in at /admin/.
SUPABASE_URL Go to supabase.com in a browser → log in → click your project → Settings (gear icon) → API → copy the "Project URL".
SUPABASE_SERVICE_KEY Same Supabase page, just below the URL: copy the long service_role "secret" key — NOT the anon one.
Important: after pasting them in Cloudflare, save both codes somewhere private (a note on your phone, a password manager). If you ever change TOKEN_PEPPER later, every activation code you already gave to customers stops working — so don't lose it, don't change it.

When all 5 are saved in Cloudflare, come back to your project folder and double-click DEPLOY-WEBSITE.bat.
